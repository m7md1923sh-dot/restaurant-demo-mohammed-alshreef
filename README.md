# Dar Al-Samar - Arabic Restaurant Demo

نموذج تجريبي لموقع مطعم عربي متجاوب، أُنشئ لعرض مهارات تطوير المواقع الإلكترونية.

## Features

- Arabic RTL responsive layout
- Interactive menu filtering
- Reservation-form validation
- Interactive FAQ section

## Ownership

صاحب النموذج: **محمد مطلق يحي الشريف**

هذا مشروع خيالي تجريبي تم إعداده بمساعدة أدوات تطوير رقمية وتحت إشراف صاحب النموذج. لا يمثل المشروع عميلاً حقيقياً ولا يحتوي على بيانات عملاء.
